# 📱 DataMaster & Spiritual Life - تطبيق المذاكرة والحياة الروحية (PWA)

تطبيق ويب تقدمي شامل (Progressive Web App) يعمل على الموبايل والكمبيوتر بدون إنترنت (100% Offline)، يجمع بين:
1. **تراك دراسة ومذاكرة هندسة البيانات (SQL & Python Data Science)** حتى ختام العام مع خوارزمية ذكية لإعادة الجدولة التلقائية.
2. **قسم الحياة الروحية الشامل:** صلوات الأجبية الأرثوذكسية بالسواعي كاملة (بنظام التابات وعارض الشرائح والعرض المتصل)، الكتاب المقدس بعهديه مع البحث والفهرس الكامل، كتاب حياة الصلاة للأب متى المسكين، وكتاب بستان الرهبان.

---

## ✨ المميزات الرئيسية:
1. **تثبيت حقيقي على الموبايل (PWA Installable):** يعمل كتطبيق أصيل على هاتفك بدون شريط متصفح مع أيقونة على الشاشة الرئيسية وشاشة بدء سريعة.
2. **تصميم عصري فائق الجمال (3D Glassmorphism):** واجهة زجاجية ثلاثية الأبعاد أنيقة، وسايد بار دراور (Sidebar Drawer) جانبي، وبار تنقل سفلي سريع (Bottom Bar)، وتبويبات تفاعلية وسريعة.
3. **يعمل بالكامل بدون إنترنت (100% Offline):** عبر Service Worker v15 وتخزين محلي `localStorage`.
4. **قسم الحياة الروحية المتكامل:**
   * **الأجبية الأرثوذكسية كاملة:** بجميع السواعي والقطع والمزامير والتحاليل والطلبة والبركة الختامية، مع 3 أوضاع للقراءة (تبويبات ليتورجية ثلاثية الأبعاد، عارض شرائح بروجكتور، وقراءة مستمرة).
   * **الكتاب المقدس (العهد القديم والجديد):** فهرس كامل لجميع الأسفار مع بحث فوري وتنقل سلس بين الإصحاحات وحفظ علامات القراءة.
   * **كتاب حياة الصلاة (للأب متى المسكين):** 262 صفحة كاملة ومنقحة نصياً بدقة فائقة.
   * **كتاب بستان الرهبان:** 353 صفحة كاملة لأقوال وسير آباء البرية القبطية منقحة وخالية من أي أخطاء طباعية.
5. **خوارزمية إعادة الجدولة الذكية (Smart Rescheduler):** إعادة توزيع الدروس المتبقية بالتساوي وتنبيهك بالحمل اليومي حتى نهاية العام.
6. **مؤقت بومودورو مدمج (60 دقيقة):** مع تنبيهات صوتية ومؤثرات احتفالية (Confetti).
7. **النسخ الاحتياطي (Backup & Restore):** تصدير واستيراد تقدمك بالكامل كملف JSON.

## 🚀 كيفية تشغيل التطبيق وتثبيته على الموبايل:

### الطريقة 1: التشغيل على الشبكة المنزلية (Local WiFi)
1. افتح موجه الأوامر (Terminal / PowerShell) داخل مجلد المشروع:
   ```bash
   cd C:\Users\mina.hany\.gemini\antigravity\scratch\study-tracker-pwa
   python -m http.server 8080
   ```
2. من هاتفك المتصل بنفس شبكة الواي فاي، افتح المتصفح واكتب عنوان IP جهازك مع المنفذ:
   `http://[IP-جهازك]:8080` (مثلاً: `http://192.168.1.15:8080`).

---

### الطريقة 2: الرفع المجاني على الإنترنت (في دقيقة واحدة)
لتثبيته على الموبايل بضغطة واحدة من أي مكان وبشهادة أمان HTTPS (المطلوبة للـ PWA):
1. **عبر GitHub Pages:**
   * أنشئ مستودع جديد على GitHub وارفع فيه ملفات المجلد.
   * من إعدادات المستودع (Settings -> Pages)، فعّل خيار نشر الفرع الرئيسي (Deploy from branch: main).
2. **عبر Vercel أو Netlify:**
   * اسحب المجلد مباشرة إلى لوحة تحكم [Vercel](https://vercel.com) أو [Netlify](https://netlify.com) لتحصل فوراً على رابط HTTPS مباشر ومجاني مدى الحياة.

---

### 📲 خطوات التثبيت على الهاتف بمجرد فتح الرابط:
* **لهواتف أندرويد (Android - Chrome):**
  1. اضغط على زر **"تثبيت التطبيق على الموبايل"** الموجود بأعلى الشاشة.
  2. أو اضغط على القائمة (الثلاث نقاط) واختر **"تثبيت التطبيق" (Install App)**.
* **لهواتف آيفون (iPhone - Safari):**
  1. افتح الرابط في متصفح **Safari**.
  2. اضغط على زر **المشاركة (Share)** أسفل الشاشة.
  3. اختر **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.

## 📁 محتويات المشروع:
* `index.html`: واجهة التطبيق الرئيسية (متوافقة تماماً مع شاشات الموبايل).
* `manifest.json`: إعدادات تعريف الـ PWA والأيقونات وشاشة البدء.
* `sw.js`: الـ Service Worker للكاش والعمل بدون إنترنت.
* `curriculum.js`: منهج الـ 43 يوماً كاملاً لمساري SQL وبايثون وتفاصيل التمارين.
* `app.js`: محرك المنطق، خوارزمية إعادة التوزيع، والمؤقتات.
* `icons/`: أيقونات التطبيق بدقة 192px و 512px و Apple Touch Icon.
